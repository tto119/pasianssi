# Klondyke Pasianssi

Pieni Klondyke (Klondike) pasianssi selaimessa, HTML + JavaScript.

Käyttö:
- Avaa `index.html` selaimessa.
- Klikkaa `Uusi peli` aloittaaksesi.
- Klikkaa noppaa (korttipakka) vetääksesi kortin pakan päältä (stock -> waste).
- Klikkaa waste tai tableau-korttia valitaksesi ja sitten klikkaa kohdepinoa siirtääksesi.
- Double-click a card to automatically move it to a foundation if possible, or click the **Auto** button to move all eligible cards to foundations.
- Tyhjälle tavulle voi siirtää vain kuninkaan (K).

Tulevat parannukset:
- Drag-and-drop, animaatiot, automaattinen siirto foundationille, parempi undo, pelin voittotarkistus ja testit.

Kehitys:
- `main.js` sisältää pelin peruslogiikan.
